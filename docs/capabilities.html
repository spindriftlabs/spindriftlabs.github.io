What Old Skool Board can do

Current capabilities

Board layout

  • Your Jira board's own columns — same names, same order, including columns that hold several statuses
  • Expand any column to see its sub-task lanes, driven by your Jira workflow
  • Split-pane layout in the expanded column — fixed parent item panel with scrollable sub-task lanes
  • Unmapped work items shown below the board, so work whose status has no column is never silently lost
  • Epic chips on cards, colour-coded to match Jira
  • Issue type icons on every card
  • Done retention on company-managed Kanban boards — hide completed items not updated in 1, 2, or 4 weeks

Work item details

Click any card title to open its full details without leaving the board.

  • Rich text description editing with bold, italic, underline, links, and lists (powered by TipTap)
  • @mentions — type @ to search and mention teammates
  • Comments — read, add, and reply
  • Linked work items and sub-tasks, with drill-in navigation
  • Detail sidebar — edit assignee, priority, labels, status, due date, and start date
  • Change issue type from the card or its details
  • Inline title editing
  • Open in Jira — Cmd/Ctrl-click a card, or click the key in the work item details

Drag-and-drop

  • Drag a parent item to choose its status and its position in one gesture — a column with several statuses shows a box per status, then an insertion line for exact placement
  • Parent item order is saved to Jira's native rank — reorder in Old Skool Board or in Jira, and each shows the same order when it loads
  • Sub-task order within a lane is kept by Old Skool Board, not Jira, and is shared by everyone in the project
  • If your board's filter isn't ordered by Rank, or you don't have Jira's Schedule work items and Edit work items permissions, reordering is switched off and the board tells you why when you try, instead of silently undoing the drop. You can still change status

Filtering

  • Text search across the board
  • Filter by issue type or label (multi-select)
  • Quick filters — toggle pills that match your Jira board's quick filter definitions
  • Type, label, and quick-filter selections are remembered per board, for your account (text search isn't)

Creating work

  • Inline creation for parent items and sub-tasks — add work without leaving the board
  • Choose the status when creating in a column that holds several statuses
  • Choose issue type when creating
  • New sub-tasks land in the correct lane and status

Board management

  • Automatically maps to your current Jira board — no setup, no status mapping
  • Settings and filters saved per board, for your account

Requirements

See also Known limitations.

  • Jira Software board, Scrum or Kanban
  • Jira Cloud (Server and Data Center are not supported)
  • Desktop browser (mobile and tablet are not supported)
  • Works best with parent items that have sub-tasks — limited value for work items without sub-tasks
  • Reordering parent items needs a board filter ordered by Rank and Jira's Schedule work items and Edit work items permissions
  • Active Marketplace license required
