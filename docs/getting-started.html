Getting started

Old Skool Board

How Old Skool Board works

Old Skool Board is an extension of a Jira Software board — there is no need to create new boards from scratch. When you open it, it reads the configuration of whichever board you're currently viewing — columns, statuses, and board type (Kanban or Scrum) — and mirrors that setup automatically.

It picks up where your board leaves off. Kanban boards show your board's work; Scrum boards show the active sprint.

Requirements

  • Jira Software board — designed to work with existing Scrum or Kanban boards; other board types are not supported
  • Jira Cloud — Server and Data Center are not supported
  • Desktop browser — mobile and tablet are not supported
  • Parent items with sub-tasks — the board's value comes from that relationship; it has limited use for flat issue structures
  • For reordering cards — your board's filter must be ordered by Rank (as Jira's default board filters are), and you need Jira's Schedule issues permission

How the board works best

Old Skool Board places each work item in whichever of your board's columns holds its status, just as Jira does. Sub-tasks use their actual Jira status, appearing as lanes inside the expanded column.

This means the board works with any workflow structure you already have.

That said, we've found it works best when:

  • Sub-tasks have their own dedicated workflow, separate from work items
  • Every status on your board's workflow is mapped to a column, so nothing ends up under Unmapped work items

When work items are kept simple and sub-tasks carry the detail, the expanded column becomes a genuinely useful view of what's actually happening inside each item. But how you structure your Jira project is entirely up to you.

Installing

Find Old Skool Board on the Atlassian Marketplace and install it to your Jira Cloud site. Once installed, it appears as a page inside your Jira projects.

Opening the board

Navigate to a Jira project and click More in the top navigation bar. In the dropdown, select Old Skool Board to open the board.

Board settings

There's nothing to set up: the board reads its columns and statuses from Jira. Click the settings icon in the top-right corner of the board to open the Board settings panel. From here you can set:

  • Done retention (company-managed Kanban boards only) — hide completed items that haven't been updated in 1, 2, or 4 weeks

Settings are saved per board, for your account only.

Known limitations

  • Backlog columns — columns with "Backlog" in their name are not shown. On Kanban boards, work items whose status only appears in a backlog column are not shown either.
  • Scrum boards without an active sprint — the board is empty until a sprint is started.
  • Creating on Scrum boards — new items go to your Jira backlog, not the active sprint, so they won't stay on the board until they're added to the sprint.
  • Done retention — available on company-managed Kanban boards only.
  • Reordering — needs a board filter ordered by Rank and Jira's Schedule issues permission. Without them, you can still change an item's status.
  • Mouse only — dragging work items has no keyboard equivalent.
