What Old Skool Board can do

Current capabilities

Board layout

  • Three-column board — To Do, In Progress, and Done — Jira statuses mapped to status categories
  • Sub-task lanes in the In Progress column, driven by your Jira workflow
  • Split-pane layout — fixed parent item panel with scrollable sub-task lanes
  • Epic chips on cards, colour-coded to match Jira
  • Issue type icons on every card
  • Kanban retention — hide completed items older than 1, 2, or 4 weeks

Issue modal

Click any card to open its full detail view without leaving the board.

  • Rich text description editing with bold, italic, underline, links, and lists (powered by TipTap)
  • @mentions — type @ to search and mention teammates
  • Comments — read, add, and reply
  • Linked issues and sub-tasks, with drill-in navigation
  • Detail sidebar — edit assignee, priority, labels, status, due date, and start date
  • Change issue type from the card or the modal
  • Inline title editing
  • Open in Jira — Cmd/Ctrl-click a card or use the modal link to jump to native Jira

Drag-and-drop

  • Reorder parent items and sub-tasks by dragging
  • Drag items between columns to trigger Jira status transitions
  • Ranking syncs to Jira — drag order updates your backlog's native rank

Filtering

  • Text search across the board
  • Filter by issue type or label (multi-select)
  • Quick filters — toggle pills that match your Jira board's quick filter definitions
  • Filter selections persist per board

Creating work

  • Inline creation for parent items and sub-tasks — add work without leaving the board
  • Choose issue type when creating
  • New sub-tasks land in the correct lane and status

Board management

  • Automatically maps to your current Jira board
  • Column-to-status mapping — map your three columns to the right Jira statuses on first use
  • Per-user preferences saved automatically

Requirements

  • Jira Cloud (Server and Data Center are not supported)
  • Desktop browser (mobile and tablet are not supported)
  • Works best with parent items that have sub-tasks — limited value for flat issue structures
  • Active Marketplace license required
